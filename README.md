# 碎片复盘

给「好像懂了，又说不出来」的人的学习复盘工具。

纯前端单文件应用，无需注册、无需联网、无需 API key——打开网页就能用。

## 它解决什么问题

学习时常有这种体验：信息进来了，也"看懂了"，但合上资料就讲不出来。理解卡在了**记忆碎片 → 结构拼接**这一步。

「碎片复盘」把这一步拆成三个动作：

1. **收集**（学的时候）：随手把关键词、一句话记成碎片卡，不打断学习
2. **拼接**（学完 5 分钟内）：把碎片拖进分组、排顺序——摆的过程本身就是思考
3. **复盘**（隔天）：合上资料，用自己的话讲一遍（写 / 说 / 翻卡），再自评命中 / 漏了 / 讲错。漏了的第二天回来，命中的间隔拉长（2 → 4 → 7 天）

配套功能：参考资料（支持粘贴文字、上传 .txt / .md / .docx / .pdf，可一键把资料里的重点转成碎片）、掌握度统计（未掌握 / 巩固中 / 已掌握 + 连续复盘天数）、JSON 备份与导入、按主题导出文本 / Word 报告。

## 使用

直接打开 `index.html` 即可（或部署到任意静态托管后访问）。所有数据只存在你自己的浏览器本地，不上传任何服务器。**换设备不会自动同步，请定期导出 JSON 备份。**

## 技术说明

- 单文件 `index.html`，原生 JavaScript，零依赖、零构建
- 数据存 localStorage；.docx 解析用浏览器原生 DecompressionStream 实现；.pdf 提取按需懒加载 pdf.js
- 部署：任意静态托管（GitHub Pages / Vercel / Netlify）即可，无需后端
